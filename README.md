# 寻物助手 · 课程 Demo

面向手机网页的桌面找物实践：说出或输入目标 → 扫描桌面 → 将手机固定在支架上 → 校准本人方向 → 接收逐步手部提示 → 由视觉大模型尝试核验是否拿到目标。使用现有视觉大模型，重点探索非视觉表达与操作流程，不另外训练手部检测或抓取算法。

## 本地启动

需要 Python 3.11 或更新版本，以及 Node.js 20.19+（20.x）或 22.12+ 与 npm；版本要求与当前 Vite 依赖一致。下面是供本地使用的命令，不代表已经在你的电脑或手机上完成验证。

在仓库根目录打开一个终端：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

在第二个终端启动网页：

```powershell
cd web
npm.cmd ci
npm.cmd run dev
```

打开终端显示的本地网页地址。开发网页通过 `/api` 代理访问本地后端。选择“模拟体验”，输入目标并点击“开始模拟寻找”；自动扫描结束后点击“已固定手机，开始校准”，依次点击三次保存位置，再等待模拟引导和核验。模拟过程中不需要真的移动手或拿起物品；听到确认反馈也仅代表模拟分支完成。“体验与连接设置”可选择未找到、拿错或遮挡场景。

## 配置 live

参照根目录 `.env.example` 在本机建立 `.env`，填写以下变量；真实密钥不放到网页代码、截图或 Git 中。

| 变量 | 用途 |
| --- | --- |
| `MODEL_API_KEY` | 模型服务密钥，仅后端使用 |
| `MODEL_BASE_URL` | 兼容服务的 API 基址，需与供应商文档及账号区域匹配 |
| `MODEL_NAME` | 有图像输入能力的模型名称 |
| `ASR_MODEL` | 服务端语音转写模型；使用同一 API 基址及密钥 |
| `APP_ACCESS_TOKEN` | 可选的应用访问令牌；开启后请求需提供 `X-App-Access-Token` |
| `MODEL_TIMEOUT_SECONDS` | 上游请求超时；不能解除画面过期限制 |
| `RATE_LIMIT_PER_MINUTE` | 后端请求频率限制 |

示例文件中的模型名称与地址只是配置起点，仍需确认账号权限及兼容性。`/api/health` 显示可用配置不等于密钥已通过真实请求验证。密钥无效、服务超时或模型输出无效时应明确报错，不会自动转成 mock 成功。

手机访问电脑的普通局域网 HTTP 地址通常不能使用相机或麦克风；**手机端需要受浏览器信任的 HTTPS**。桌面 `localhost` 的例外不等于手机上的局域网 IP 也可用。仅改监听地址、启动开发服务器或执行构建，都不构成 HTTPS 配置或生产部署；课堂上配置受控的 HTTPS 访问后，另测授权、暂停和网络异常。

live 使用固定支架和安全桌面物品。每次移动相机、切后台或暂停引导后按流程重新校准。方向以参与者本人为准；画面过旧、手或目标不可见时应停止移动提示。不要因为目标消失或手与物品重叠，就将其视作成功抓取。

## 范围与后续

当前工作面向课程桌面 Demo；没有承诺任意物品、任意环境都能识别，也没有完成视障用户验证、手机型号兼容认证或生产上线。新增测试事实应写进独立结果记录，不预先填入成功率或延迟数据。

后续可以用 Capacitor 复用网页界面，但还需适配原生相机、录音、语音、权限、网络与应用生命周期，并重新测试；本仓库的网页实现不表示原生 App 已完成。历史报告和预览文件保留在原电脑的 `deliverables/`，不纳入首次开发仓库；[归档说明](deliverables/README.md)列出边界。旧报告不作为当前Demo已实现能力的证明。
